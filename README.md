# Bash-Fundamentals
## What is bash 
Bash (Bourne Again SHell) is a command-line interpreter and scripting language that is meant for Unix-like operating systems. Bash is the main way you can interact with linux systems, whether you want to secure them or break into them. 
## How is this repo is helping me learn and practice bash
This repo helps me learn and practice bash by teaching me new things about basic concepts, and just providing extra scripting practice. An example of this is how I did not know that there was a preset variable for the read command ($REPLY) that is used when the read command is not provided a variable to assign to.
